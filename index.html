FAQ

Common questions

Do I need coding or technical experience?
No coding required. ClipPipeline installs like any Windows application. The built-in setup wizard guides you through connecting your API keys and YouTube channels step by step in about 5–10 minutes.
What are the ongoing API costs outside my subscription?
You'll need an OpenAI API key for script writing and voiceovers — roughly $0.08 per video, billed directly by OpenAI. At 25 videos/day that's around $60/month. Reddit access is completely free and requires no API key.
What operating systems are supported?
ClipPipeline is currently a Windows 10/11 desktop application. Mac and Linux support are planned for a future release. You can run it on a Windows VPS for 24/7 operation without keeping your PC on.
Can I choose my own niches and subreddits?
Yes, fully customizable. You choose which subreddits each channel pulls from, set quality thresholds, adjust upload schedules, and configure script prompts to match your brand voice and target audience.
What if a video fails to upload?
Every error is logged and visible in the dashboard. Failed uploads can be retried with one click. YouTube OAuth tokens refresh automatically in the background so uploads keep running without interruption.
Do I need to provide my own background videos?
Pro and Ultimate plans include a background video pack. Starter users can download free gameplay footage using the built-in yt-dlp integration. Landscape videos are automatically formatted with blur for proper 9:16 vertical format.
Are my API keys and YouTube credentials secure?
Your API keys and YouTube OAuth tokens are stored locally on your machine only. ClipPipeline never transmits your credentials to our servers — everything runs entirely from your PC.
How do I cancel my subscription?
Cancel anytime from the Stripe customer portal — no phone calls, no forms, one click. You keep access until the end of your current billing period with no additional charges.
